# The First Handshake: Hello, World.

If you are reading this, the CI/CD pipeline worked. The Terraform code successfully provisioned the infrastructure, the Azure Functions are firing, and the frontend is pulling data from a global CDN. 

**This isn't just a resume; it's a living, breathing cloud environment.**

### Why I Built This
Coming from a blue-collar background, I was taught that if you're not willing to sign your name to your work, you're not doing it right. I wanted a challenge, I found myself having a hard time sticking to one thing. I would commplete something and find myself stuck looking for another project. This website has been live since April 1st but I have constantly been adding, breaking and fixing things on here for over a month to completely polish it. 

I built daneondemand.com to bridge the gap between "knowing" and "doing." I have the certifications, but I didn't have the hands on to back it all up. 

### The Tech Stack (The "Guts")
* **Frontend:** A modern React application styled with "Glassmorphism" to match my love for clean, transparent design.
* **Infrastructure:** 100% defined in Terraform. I can destroy this entire site and have it back online in under five minutes with a single command.
* **Backend:** Serverless Azure Functions written in Python, handling the visitor telemetry.
* **Database:** Cosmos DB (NoSQL) for high-speed, global data storage.
* **CI/CD:** GitHub Actions handles the heavy lifting—every time I push code, Azure automatically rebuilds and deploys the site.

### The "Live" Proof
Scroll down to the footer. You’ll see a Service Health Dashboard. It’s pulling real-time data from the GitHub API and Azure to show you exactly when I last touched this code and the health of the East US region.
