# Cloud Resume Challenge

This is my very first cloud project! I built a complete serverless web application using **Microsoft Azure** to host my resume online and track visitor counts.

## The Tech Stack
- **Frontend:** Hosted on Azure Blob Storage and distributed globally with Azure CDN.
- **Backend:** A serverless Azure Function.
- **Database:** Azure Cosmos DB to store the visitor count.
- **CI/CD:** GitHub Actions for automated deployments.

Check out the architecture and code on my [GitHub Repository](https://github.com/Dane139/cloud-resume-challenge).
