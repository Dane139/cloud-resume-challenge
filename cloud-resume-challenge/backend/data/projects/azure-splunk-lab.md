# Project Details

This project focuses on cloud security monitoring and threat detection by creating a unified security operations center (SOC) environment. I integrated cloud-native telemetry from Azure with Splunk to gain deeper visibility into my infrastructure.

## Key Objectives
- **Telemetry Aggregation:** Collected logs from Azure resources (Activity Logs, Entra ID, and Virtual Network traffic).
- **Security Analytics:** Developed custom Splunk queries to visualize cloud security events and identify anomalous behavior.
- **Threat Detection:** Configured alerts for common attack vectors, such as brute-force attempts and unauthorized API access.
- **Automation:** Implemented basic automated response triggers to isolate compromised resources.
