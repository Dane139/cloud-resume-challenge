# Project Details

This project centers on the implementation of vulnerability management workflows within a cloud environment. By deploying Nessus, I gained practical experience in identifying misconfigurations and software vulnerabilities across Azure infrastructure.

## Key Objectives
- **Infrastructure Deployment:** Provisioned Azure Virtual Machines using Terraform to create a test environment.
- **Vulnerability Scanning:** Configured Nessus scanners to perform credentialed (authenticated) scans against Linux and Windows hosts.
- **Risk Assessment:** Analyzed scan reports to prioritize vulnerabilities based on CVSS scores and exploit availability.
- **Remediation:** Documented and executed patching strategies to mitigate identified security risks.
